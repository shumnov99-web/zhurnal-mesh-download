# Журнал МЭШ. Преподаватель — скачать

Приложение для телефона: журнал МЭШ под рукой, быстрая выставка отметок.

## Android (APK)

Скачать: https://github.com/shumnov99-web/zhurnal-mesh-download/releases/download/v1.8/Zhurnal-MESH-Android-1.8.apk

1. Нажмите ссылку (или наведите камеру на QR-код) — телефон скачает файл.
2. Откройте скачанный файл. Если Android спросит про установку из этого
   источника — разрешите.
3. Установите. Данные журнала сохранятся.

## iPhone

Файл `MeshJournal-iPhone-1.8.ipa` лежит в этом же релизе. Он ставится через программу Sideloadly
на компьютере со своим Apple ID (приложение подписывается вашим аккаунтом).

## Что нового в версии 1.8

* Окна подстраиваются под размер экрана: на любой диагонали и под любой
  версией Android (10–17) список учеников не закрывает журнал.
* Колонка с фамилиями больше не занимает пол-экрана — длинные имена
  переносятся, рядом видны даты и можно выставлять отметки.
* Размер шрифта системных настроек больше не ломает вёрстку.
